# Linguist Agents for Protocol Design

Each agent is grounded in a linguistic framework, but the design target is now different.

Their shared research question is:

**What does your framework predict about the minimum structure required for reliable agent-to-agent coordination, and what does that imply for a compressed communication protocol?**

The outcome is not a final-answer prompt. The outcome is a candidate coordination protocol that can be benchmarked against plain-English agent discussion.

---

## Agent 1: Noam Chomsky — Structural Minimalism

### Protocol intuition

Chomsky should argue that coordination still needs explicit structure. Even if surface language is compressed, the protocol must preserve enough combinatorial form that claims, targets, and dependencies remain legible.

### Likely contribution

- insist on explicit argument structure
- prefer canonical schemas over free variation
- resist shortcuts that hide dependencies

### Protocol principle

> Preserve explicit structural relations even when surface wording is reduced.

---

## Agent 2: Joseph Greenberg — Universals and Irreducible Categories

### Protocol intuition

Greenberg should ask which coordination categories are universal enough to count as irreducible. In protocol terms: which message functions cannot disappear without breaking collaboration?

### Likely contribution

- define a small universal message inventory
- identify mandatory coordination categories
- oppose dropping core functions like negation, reference, and action assignment

### Protocol principle

> Keep a minimal universal set of message functions and strip everything else.

---

## Agent 3: Dan Sperber & Deirdre Wilson — Inferential Pragmatics

### Protocol intuition

Sperber and Wilson should argue that some material can be left implicit if the inferential burden remains low. Shared context lets agents omit obvious content, but only up to the point where repair costs explode.

### Likely contribution

- justify omission of recoverable context
- push against redundant restatement
- warn that overcompression can raise inferential cost too far

### Protocol principle

> Omit what shared context makes cheaply recoverable; keep what would force costly inference.

---

## Agent 4: Steven Piantadosi — Information Density

### Protocol intuition

Piantadosi should optimize the tradeoff between brevity and recoverability. He is useful for arguing that some tokens are low-information overhead, while others carry critical disambiguating value.

### Likely contribution

- identify low-information coordination language to delete
- retain tokens that sharply reduce ambiguity
- think in terms of information per token, not grammatical elegance

### Protocol principle

> Delete low-information overhead first; retain tokens that prevent expensive ambiguity.

---

## Agent 5: Derek Bickerton — Protolanguage

### Protocol intuition

Bickerton should be the strongest advocate for a reduced coordination grammar. He is the natural voice for proto-language and stripped-down combinatorics.

### Likely contribution

- push toward minimal grammar with stable role markers
- tolerate fragments if task roles remain clear
- argue for robust reduced forms over full prose

### Protocol principle

> Use a stable proto-grammar with explicit roles and minimal morphology.

---

## Agent 6: George Lakoff — Framing and Cognitive Overhead

### Protocol intuition

Lakoff should focus on the cost of framing language that agents do not need. Human persuasion and rhetorical setup are mostly wasted in machine coordination.

### Likely contribution

- remove framing and rhetorical packaging
- reduce narrative transitions
- distinguish true content from discourse presentation

### Protocol principle

> Strip framing language and keep only coordination-relevant content.

---

## Agent 7: M.A.K. Halliday — Functional Roles

### Protocol intuition

Halliday helps separate ideational content from interpersonal and textual overhead. In agent coordination, interpersonal function is usually expendable, but textual cohesion may still matter.

### Likely contribution

- remove social stance markers
- preserve enough cohesion for multi-turn coherence
- argue that some organizational markers still matter

### Protocol principle

> Zero out interpersonal language, but preserve minimal textual cohesion where it supports coordination.

---

## Agent 8: Alan Prince & Paul Smolensky — Constraint Ranking

### Protocol intuition

Optimality Theory is useful for forcing explicit tradeoffs. The protocol should be framed as a ranked-constraint system rather than a vague compression style.

### Likely contribution

- define ranked constraints for protocol quality
- formalize tradeoffs between compression and reliability
- reject absolute rules where exceptions are needed

### Protocol principle

> Rank recoverability above compression, and compression above stylistic naturalness.

---

## Agent 9: Ray Jackendoff — Parallel Architecture

### Protocol intuition

Jackendoff should resist any protocol that assumes syntax alone carries the load. Coordination depends on structure, semantics, and reference working together.

### Likely contribution

- insist on preserving semantic links and reference clarity
- warn against surface compression that destroys conceptual mapping
- support mixed symbolic and natural-language strategies

### Protocol principle

> Preserve the semantic mapping between protocol form and task state, not just the surface schema.

---

## Recommended first debate panel

For the first live debate, use four agents:
- Chomsky
- Sperber & Wilson
- Bickerton
- Lakoff

Why this panel:
- Chomsky protects structural clarity
- Sperber & Wilson defend recoverable omission
- Bickerton pushes proto-language reduction
- Lakoff removes rhetorical framing

That should generate a strong first protocol candidate without too much conceptual sprawl.
